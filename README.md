## 🌿 About me

**Founder of [MintHost](https://minthost.org) and [MintBreeze](https://mintbreeze.org). I build AI-powered tools for small businesses, plus Discord bots.**

Small businesses lose customers every day to missed calls, slow replies, and websites that don't convert. I build the software that fixes that, and I ship it end to end: product, code, infrastructure, and support.

- 📞 **MintBreeze** picks up the phone, answers email, follows up, and books appointments, so owners never miss a customer.
- 🚀 **MintHost** turns website visitors into booked customers, and builds and hosts the site they land on.
- 🤖 **Zeltra** keeps Discord communities safe and organized, with privacy built in from day one.
